# ElOnceIdeal

Prototipo de un sitio web dedicado al fútbol europeo, centrado en las cinco principales ligas: **LaLiga, Premier League, Bundesliga, Serie A y Ligue 1**.

El proyecto incluye páginas para consultar información sobre ligas, equipos, jugadores y partidos, además de una sección de noticias. Se desarrolló utilizando HTML5, CSS y JavaScript, aplicando distintas técnicas de maquetación adaptable e integración de datos mediante XML y JSON.
